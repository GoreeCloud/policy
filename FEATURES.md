# Features

## Implemented in source

- Deterministic policy request validation and evaluation.
- Explicit six-state decision vocabulary.
- Conflict-safe policy composition for matching rules.
- Rule-authority, version, timestamp, and matched-rule provenance.
- Local-only reference evaluation service.
- Health/readiness payloads separated from policy decisions.
- Standard-library unit tests and CI workflow.

## Not yet implemented or accepted

Production authentication, durable policy storage, signed bundles, distribution, Mesh transport, Manager administration, live enforcement adapters, Everkeep recovery, Observability publication, and Stable/production certification remain planned or blocked. See `PLANNED-FEATURES.md`.
